## 2. 近期

### 测试

- [x] 用 `node:test` + 假 LLM 测试全部后端接口和前端 service、文案（`npm test`，推送前自动运行）。
- [ ] 前端组件渲染测试（拖动排序、人物表单、润色 / 预测弹窗）：需要加 Vitest + Testing Library 作为开发依赖。

### 代码规范遗留

- [ ] `LineItem` 编辑台词时的中文 / 英文输入框补上 label（现在只有 placeholder"中文 / 英文"）。
- [ ] 底部 `Composer` 的台词输入框补上 `aria-label`（属于规范里的例外，可以不显示 label）。
- [ ] 编辑中的台词行没有拖动手柄，ID 会左右错位一点，可以给它留出手柄的位置。

### 去掉写死的人物

- [ ] 新建场景时默认带的人物名单（`server.js` 的 `DEFAULT_CHARACTERS`）还是生化危机的人物，改成空名单，或者从上一个场景复制。
- [ ] 台词颜色写死了 Leon 和 Ada（CSS 变量 `--leon` / `--ada`，类名 `speaker-leon` / `speaker-ada`），改成按人物在名单里的顺序自动分配颜色。

### 使用体验

- [ ] AI 预测弹窗里直接选模型（现在用底部的 LLM 下拉列表，需要先关掉弹窗再切换）。
- [ ] 人物名单可以从别的场景导入：现在每个场景各有一份名单，同一个人物的性格档案要在每个场景重新填一遍。
- [ ] 免费额度用完（429）时给出更明确的提示，比如"今天的免费额度已用完，换一个模型试试"，而不是显示原始报错。

## 3. 候选功能

还没决定要不要做，按大概的优先级排列。

- 在两句台词之间直接插入新台词（现在可以先加到末尾再拖上去）。
- 把台词移动到另一个场景。
- 按说话人筛选、搜索台词。
- 导出为剧本格式（Markdown / 纯文本），可以按场景导出。
- 整个场景一次性润色，逐句选择版本。
- 保存润色历史，可以回到之前选过的版本。
- 场景排序。
- 用预测日志（`logs/predict.jsonl`）统计预测的准确率，比如原台词模式下有多少次找到了场景位置。

## 4. 已完成

只列大块功能，细节见 PRD 和 git 记录。

- 场景和台词的增删改，独立网址，中英文界面切换。
- 台词中英双语存储，列表显示"中文名：中文 / 英文名: English"，悬停显示编辑、润色、复制、删除。
- AI 润色：三个可配置的风格，选定版本后可以修改、再次润色。
- AI 预测后续台词，可以按原剧本逐句取原台词（只让模型翻译中文），并记录最近 100 次预测日志。
- 场景的原剧本参考（`source`）和人物的性格 / 台词参考，润色和预测时自动发给 LLM。
- 多个 LLM 服务通过 `.env` 配置，长参考按服务设置读取上限。
- 开发时后端（`node --watch`）和前端（Vite）改代码后自动重启 / 刷新。
